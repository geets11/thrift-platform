                    EXACT COMMANDS TO GET PRODUCTS SHOWING

🎯 WHAT YOU NEED TO DO:
This Laravel project needs to be run on YOUR LOCAL MACHINE (not in the browser).
It needs PHP to work. Follow the steps below.

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 1: PREREQUISITES
Make sure you have installed:
  - PHP 8.1+ (https://www.php.net/downloads)
  - Composer (https://getcomposer.org/download)  
  - Node.js (https://nodejs.org)

Verify installation:
$ php --version
$ composer --version
$ node --version

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 2: NAVIGATE TO PROJECT

Open Terminal/Command Prompt and type:

$ cd /path/to/thrift-platform

(Replace /path/to/thrift-platform with actual path)

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 3: INSTALL PHP DEPENDENCIES

$ composer install

Expected time: 2-5 minutes
This downloads all PHP packages needed for Laravel.

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 4: COPY ENVIRONMENT FILE

$ cp .env.example .env

(On Windows, use: copy .env.example .env)

This creates your .env configuration file.

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 5: GENERATE APP KEY

$ php artisan key:generate

Expected output: Application key set successfully.

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 6: CREATE DATABASE FILE

$ touch database/database.sqlite

(On Windows, use: type NUL > database\database.sqlite)

This creates the SQLite database where products will be stored.

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 7: CREATE DATABASE TABLES

$ php artisan migrate

Expected output should show:
  ✓ Creating table users
  ✓ Creating table categories
  ✓ Creating table products
  ✓ Creating table cart_items
  ✓ Creating table notifications
  ... etc

This creates all the database table structure.

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 8: ADD SAMPLE PRODUCTS (THIS IS THE KEY!)

$ php artisan db:seed

Expected output: Database seeding completed successfully.

THIS COMMAND ADDS:
  ✓ 2 sample user accounts
  ✓ 5 product categories
  ✓ 20+ sample products with images
  ✓ Products are now in the database!

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 9: SET UP IMAGE STORAGE

$ php artisan storage:link

Expected output: The [public/storage] link has been connected.

This makes product images accessible.

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 10: INSTALL NODE DEPENDENCIES

$ npm install

This installs JavaScript/CSS packages.

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 11: START LARAVEL SERVER

Open Terminal Window 1 and type:

$ php artisan serve

Expected output:
   Laravel development server started: http://127.0.0.1:8000

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 12: START FRONTEND COMPILER

Open Terminal Window 2 (different window!) and type:

$ npm run dev

This compiles CSS and JavaScript.

═══════════════════════════════════════════════════════════════════════════════

✅ STEP 13: OPEN IN BROWSER

Open your web browser and visit:

http://localhost:8000

YOU SHOULD NOW SEE:
  ✓ Homepage with thrift platform
  ✓ Shop link at top
  ✓ Products displaying with images
  ✓ Shopping cart working
  ✓ All features functional!

❌ TROUBLESHOOTING

Issue: "php: command not found"
Solution: PHP is not installed
→ Install PHP from https://www.php.net/downloads
→ Add PHP to your PATH environment variable
→ Restart terminal

Issue: "SQLSTATE[HY000]: General error: 1 no such table"
Solution: Migrations didn't run
→ Run: php artisan migrate
→ Run: php artisan db:seed

Issue: "Class 'PDO' not found"
Solution: SQLite extension not enabled in PHP
→ Edit php.ini and uncomment: extension=pdo_sqlite

Issue: "Images not showing"
Solution: Storage link not created
→ Run: php artisan storage:link

Issue: "Connection refused"
Solution: Laravel server not running
→ Run: php artisan serve

Issue: "npm: command not found"
Solution: Node.js not installed
→ Install from https://nodejs.org

🎓 WHAT EACH COMMAND DOES:

composer install
  → Downloads all PHP packages Laravel needs

php artisan key:generate
  → Creates encryption key for your app

php artisan migrate
  → Creates all database tables from migration files

php artisan db:seed
  → Fills database with sample products/users/categories

php artisan storage:link
  → Creates link so images can be accessed from web

npm install
  → Downloads all JavaScript/CSS packages

php artisan serve
  → Starts the web server on http://localhost:8000

npm run dev
  → Compiles and watches CSS/JavaScript files
