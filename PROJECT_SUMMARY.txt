================================================================================
                      HOW TO RUN THE PROJECT
================================================================================

STEP 1: Setup Environment
```
cp .env.example .env
php artisan key:generate
```

STEP 2: Configure Database
Edit .env file:
- DB_DATABASE=thrift_platform
- DB_USERNAME=root
- DB_PASSWORD=your_password

STEP 3: Run Migrations
```
php artisan migrate
php artisan storage:link
```

STEP 4: Start Servers
Terminal 1:
```
php artisan serve
```

Terminal 2:
```
npm run dev
```

STEP 5: Access Application
Open: http://localhost:8000

================================================================================
                     WHAT YOU NEED TO KNOW
================================================================================

PROJECT STRUCTURE:
- App Logic: app/Http/Controllers/ and app/Models/
- User Interface: resources/views/
- Routes: routes/web.php
- Database: database/migrations/
- Storage: storage/app/public/

KEY CONTROLLERS:
1. ProductController - Browse and view products
2. CartController - Shopping cart operations
3. CategoryController - Browse categories
4. AdminProductController - Manage products (seller)

KEY MODELS:
1. Product - Product details and relationships
2. User - User with roles (buyer, seller, admin)
3. Cart - Shopping cart
4. CartItem - Items in cart
5. Category - Product categories

MAIN ROUTES:
- /shop - Product listing
- /shop/{product:slug} - Product details
- /cart - Shopping cart
- /admin/dashboard - Seller dashboard
- /admin/products - Manage products
- /login, /register - Authentication

DATABASE RELATIONSHIPS:
- User → Many Products (as seller)
- User → One Cart
- Cart → Many CartItems
- CartItem → One Product
- Product → One Category
- Category → Many Products

================================================================================
                      TROUBLESHOOTING QUICK REFERENCE
================================================================================

ERROR: Images not displaying
SOLUTION: php artisan storage:link

ERROR: Database connection error
SOLUTION: Check .env file, run php artisan migrate

ERROR: 500 Internal Server Error
SOLUTION: Check storage/logs/laravel.log

ERROR: Routes not working
SOLUTION: php artisan cache:clear

ERROR: CSS not loading
SOLUTION: npm run dev (in another terminal)

ERROR: "CSRF token mismatch"
SOLUTION: Ensure @csrf is in all forms

ERROR: Module/class not found
SOLUTION: composer install, npm install

================================================================================
                         QUESTIONS LIKELY TO BE ASKED
================================================================================

1. "How do you prevent SQL injection?"
   Answer: Use Eloquent ORM with parameterized queries

2. "How do you hash passwords?"
   Answer: Laravel's Authenticatable trait uses bcrypt

3. "How do you handle file uploads?"
   Answer: ImageUploadService validates and stores securely

4. "Why slug-based URLs?"
   Answer: SEO friendly, more readable than IDs

5. "How do you manage relationships?"
   Answer: Eloquent relationships defined in models

6. "How do database migrations work?"
   Answer: Version control for database schema

7. "What's the benefit of this architecture?"
   Answer: Maintainable, scalable, follows Laravel conventions

8. "How do you handle validation?"
   Answer: Form request validation in controllers
